# Changelog

- 2026-10-23, 1.2.0: New Arbs tab, using only your own books and the prices already scanned (no extra Odds API calls). Arbs shows the best price on each side when they add up to under 1, with ROI and a whole dollar stake split for a total you enter. Middles finds spreads and totals where two of your books hang different lines, with the chance of landing in the gap (Gridiron's NFL key number table for NFL spreads, a normal curve with an editable standard deviation per sport for the rest) and the pair's EV per $100. Both lists show each price's age and hide prices past a new stale setting, and a new minimum EV setting hides the small ones.
- 2026-10-14, 1.1.0: Fair prices can now be worked out four ways (multiplicative, additive, power and Shin, in a new fairprice module), with Shin as the default and every fair price labeled with its method. A new EV gate setting, worst case by default, counts a price as an edge only when it beats fair under all four: the Edges list, highlights, alerts and every Bet or Pass follow it.
